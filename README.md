# continual_learning_lrls
1. Use gpu_1_mtop.sh for changing the parameters and to start continual learning. The current code supports random and POS bases code switching.
2. Download MTOP dataset from Huggingface - https://huggingface.co/datasets/mteb/mtop_domain
3. Use Facebook MUSE for bi-lingual dictionaries - https://github.com/facebookresearch/MUSE
   
Note: Make sure to change the paths accordingly

Paper Link - https://aclanthology.org/2026.eacl-long.293/
